# IrCodeyBadge

Is true Codey companion for [g33kOS](../../../CodeyRocky/geekOS.md) 
When you pick IrBadge on Codey geekOS menu this app will let you change the text via Infrared.
This app sends a text message to a Codey badge over IR.
Characters are separated by Unit Separator (ASCII 31), and the message ends with a newline so Codey can distinguish repeated characters and message end.
NEC command bits are reversed because Codey's decoder reports them in wire order.
