# IrCodeyReciver

Small App which recieves Text or Infra red from Codey.
Main purpose of app si debuging of Codey Ir comunications.
More about codey Ir communication [here](../../../CodeyRocky/IrCommunication.md).
On display app shows only text recieved but in serial line and log file it provides details.
- Raw signals
- Binary convertion
- Hexadecimal values
- ASCII
